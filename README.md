# ⚡ Computação Paralela

Implementações e estudos de computação paralela desenvolvidos em C++ durante a disciplina de Computação Paralela na UFERSA, utilizando OpenMP e MPI.

## 📂 Estrutura

```
computacao-paralela/
├── unidade2/   # Paralelismo com OpenMP
└── unidade3/   # Exercícios avançados de paralelismo
```

## ▶️ Como executar

### Pré-requisitos

- GCC com suporte a OpenMP (`g++`)
- Linux ou WSL recomendado

### Compilar e executar

```bash
g++ -fopenmp -o programa arquivo.cpp
./programa
```
